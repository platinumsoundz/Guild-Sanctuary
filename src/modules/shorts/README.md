# Shorts

Owns the immersive vertical short-video feed and short-specific likes/comments. The feed uses vertical scroll snapping, native touch scrolling, inline video controls, muted looped playback, and per-clip comment threads. Each world has a separate in-memory clip repository. Signed-in users can select a local video or record a short clip using the browser camera/microphone APIs, preview it, and publish into the active world's demo feed. Free demo accounts see an explicitly labeled ad placeholder; paid VIP demo tiers do not. Production needs managed upload/transcoding, authorization, moderation, durable counters, CDN delivery, and approved ad-provider integration.
