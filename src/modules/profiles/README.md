# Profiles

Owns user profile presentation, rich customization, per-field privacy controls, social-link visibility, own-post/media showcase, and public profile discovery. `ProfileDashboard` edits picture/banner, theme color, unlocked frame, bio, location, age, star sign, belief, and public visibility flags. The theme picker previews the profile accent across the application; banner selection updates the profile-card preview and saves with the profile. Facebook, X/Twitter, and YouTube URLs are stored in the typed `Profile.socialLinks` contract and are returned publicly only when the social-links privacy flag is enabled. Wallets, paid top-ups, and the inventory are owned by `src/modules/economy/`.

Public profile search returns verified, discoverable profiles and never exposes email addresses; personal details are returned only when their matching privacy switch is enabled. Image URLs and local image uploads are saved in the browser demo session, not a production media store. Use shared contracts from `src/types` at module boundaries and import another module only through its public entry point.
