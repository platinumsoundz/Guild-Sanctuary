# Economy

The Wallet page is the first persistent economy feature. It displays the signed-in Supabase user's token balance and recent bundle purchases. Guest and local-demo accounts cannot buy tokens, and the browser never changes wallet balances.

Token bundles are configured as GBP 100/£1, 600/£5, and 1,200/£10. Checkout is created server-side by the authenticated `token-checkout` Supabase Edge Function using fixed Stripe Price IDs. Credits are granted only after a signature-verified Stripe webhook calls the service-only, idempotent database function. Bundle cards remain disabled until `TOKEN_CHECKOUT_ENABLED=true` and the expected Edge Function secrets are present.

The shareable Stripe Payment Link is not used for wallet purchases because it cannot safely associate an individual checkout with the signed-in Sanctuary account. Do not share/use that link for in-app token sales; direct purchases through it will not be credited to a wallet. Do not set `TOKEN_CHECKOUT_ENABLED=true` until the migration, functions, Price IDs, live/test mode, webhook endpoint, and successful end-to-end test are all confirmed.

This first release has no token spending, transfers, marketplace, cash-out, VIP unlock, post promotion, cosmetics, or gifts. Those are planned extensions and must be implemented with server-side ledger transactions and clear product rules before use. The wallet and ledger are account-bound; deleting an account deletes its stored wallet history. The system currently records verified purchases only; refund/chargeback reconciliation must be added before enabling token spending or trading.
