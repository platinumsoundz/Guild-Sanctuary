# Economy

Owns wallet balances, credit packages, VIP tiers, cosmetic catalog, inventory, and equipment state. `service.ts` owns the module's wallet/product contracts and provides an in-memory demo adapter; `useWallet.ts` is its typed UI hook, and `WalletPanel` exposes mock checkout, tier unlocks, and cosmetic management.

The UI's `stripe-mock` checkout never contacts Stripe or charges money, and its wallet/inventory snapshots remain browser-local and editable. The current app does not create real checkout sessions or connect local demo accounts to Supabase Auth. Stripe is used only for optional, account-unlinked community tips; the current tip flow is disabled by default and must remain so until production credentials, a verified deployment origin, and the Supabase migration are configured and tested. Lemon Squeezy digital-goods checkout and Monzo Business contributions are product decisions, not implemented payment paths. Never enable live digital-goods payments until server-authoritative identity, durable entitlements, refund/reconciliation handling, and operational review are complete.
