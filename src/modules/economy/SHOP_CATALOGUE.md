## Ownership and release rules

- Items are permanent account entitlements. Switching an active theme does not remove ownership.
- No user listings, transfers, trading, cash-out or gameplay advantages are part of this shop.
- The catalogue is readable while purchases remain disabled.
- Token redemption stays locked until the owner reviews the migrations and isolated staging tests verify balance checks, idempotency, ledger consistency, ownership, theme entitlement enforcement and cosmetic equip behavior.
- These are the revised intended prices. The repricing migration is **NOT APPLIED** to any remote database by this code change.
